🎮 Video Game Sales Dashboard | Power BI

📌 Project Overview

This project explores video game sales data using Microsoft Power BI. The dashboard provides insights into video game sales performance across different genres, gaming consoles, geographical regions, and years.

The goal of this project is to organise sales data into interactive visualisations that make it easier to explore trends and compare performance across different categories.

🎯 Project Objectives

Analyse total video game sales across different genres and consoles.

Compare sales performance across North America, Japan, PAL regions, and other markets.

Explore video game sales trends over time.

Identify genres and consoles with higher recorded sales.

Present sales data through an interactive dashboard.

📊 Dashboard Features

Total Sales: Displays overall recorded video game sales.

Top-Selling Games: Compares game titles based on total sales.

Sales by Genre: Shows how total sales are distributed across video game genres.

Sales by Console: Compares total sales across gaming consoles.

Regional Sales Analysis: Examines sales across North America, Japan, PAL regions, and other markets.

Sales Trends: Visualises sales performance over time.

Interactive Filters: Allows users to explore the dashboard using genre and month filters.
